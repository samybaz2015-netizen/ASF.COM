# عصف — Asf

مساحة عمل مستقلة لتحديث برنامج عصف ونشره على SmarterASP.NET.

| المجلد | الغرض |
|--------|-------|
| `src/` | الكود المصدري |
| `backup/` | نسخة الإصدار الحالي قبل التعديل |
| `docs/` | التوثيق وسجل النشر |

مفصول تماماً عن `E:\عطاء الجزيرة` — ملفات منفصلة، إعدادات منفصلة، قاعدة بيانات منفصلة.
