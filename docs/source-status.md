## 1. الواجهة الأمامية (Frontend)

تطبيق **React** مبني بـ create-react-app. المنشور على الخادم هو ناتج البناء، لكن **خرائط المصدر
(`.js.map`) مرفوعة معه**، وهي تحتوي نص كل ملف مصدر كما كتبه المطور.

استُخرج المصدر من الحزمة الحيّة `main.aee1547c.js.map` إلى `src/frontend/`:

| المؤشر | القيمة |
|--------|--------|
| ملفات مصدر | 226 |
| مجلدات | 134 |
| حجم الكود | 1.3 ميجابايت |
| صفحات (`Pages/`) | نحو 40 |
| حزم npm مستخدمة | 90 |

أهم الحزم: `@mui/material` · `@reduxjs/toolkit` · `@tanstack/react-query` · `axios` ·
`chart.js` · `leaflet` · `jspdf` + `jspdf-autotable` · `html2canvas` · `jszip` · `framer-motion`.

عنوان الواجهة الخلفية مثبّت في `src/frontend/util/Apiconfig.js`:
`https://asfconsult-002-site1.ftempurl.com` — أي النطاق المؤقت، لا `asf-consulting.com`.

### الناقص لإعادة البناء
خريطة المصدر تحوي ملفات الكود فقط، ولا تحوي:
- `package.json` (قائمة الاعتماديات وإصداراتها) — يُعاد بناؤه من قائمة الحزم الـ90
- مجلد `public/` — متوفر فعلياً في `backup/.../frontend/` (index.html والصور والأيقونات)
- ملفات الإعداد (`.env`, `jsconfig.json` إن وُجدت)

**الحالة:** قابل للتحديث بعد إعادة تركيب `package.json` وتثبيت الحزم.

## 2. الواجهة الخلفية (api)

**ASP.NET Core** منشور ومترجَم. لا يوجد أي ملف `.cs` أو `.csproj`.

تجميعات المشروع الأربع:

| الملف | الطبقة |
|-------|--------|
| `RASM.Api.dll` | واجهة HTTP والتحكمات |
| `RASM.Core.dll` | النماذج والمنطق الأساسي |
| `RASM.Repository.dll` | الوصول للبيانات |
| `RASM.Service.dll` | خدمات التطبيق |

معها أربعة ملفات `.pdb` بصيغة **Portable PDB** (توقيع `BSJB`) — تحمل أسماء الدوال وأرقام
الأسطر، وتحسّن كثيراً جودة أي عملية فك ترجمة.

التقنيات المستخدمة (من المكتبات المرفقة): EF Core مع SQL Server، مصادقة JWT،
ASP.NET Identity، AutoMapper، Google Drive API v3، وأيضاً مزوّد MySQL (Pomelo) — غير مستخدم
على ما يبدو لأن سلاسل الاتصال كلها SQL Server.

**الحالة:** غير قابل لتعديل المنطق مباشرة. الخيارات في قسم القرارات أدناه.
